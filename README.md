# 🌐 Bhaskar Pathriya – Interactive 3D Portfolio

### Built with **React, GSAP, Three.js, TailwindCSS**

This is a fully animated, interactive portfolio designed to **impress clients, recruiters, and hiring managers**.  
More than a portfolio — it’s a **complete web experience**, featuring production-grade code, scroll-based animations, and real-world best practices.

---

## 🚀 Tech Stack

| Technology          | Description                                            |
| ------------------- | ------------------------------------------------------ |
| ⚛️ **React (Vite)** | Fast dev server and optimized production build         |
| 🎨 **Tailwind CSS** | Utility-first styling for modern UI components         |
| 🌀 **GSAP**         | Scroll-based motion and smooth animations              |
| 🌍 **Three.js**     | 3D visuals powered by React Three Fiber                |
| 🧩 **Drei**         | Essential helpers for 3D rendering and camera controls |

---

## ✨ Features

- 🔥 **3D Hero Section** — animated planet & golden ring built with Three.js
- 🧭 **Smooth Navbar** — staggered link animations and scroll interactions
- 🎯 **Services Section** — scroll-triggered layout with word motion effects
- 🖼️ **Projects Showcase** — hover overlays, live project previews & dynamic backgrounds
- ✍️ **About Section** — image reveal, typewriter text, and soft transitions
- 💬 **Contact CTA** — marquee-style invitation for hiring or collaboration
- 💼 **Fully Responsive** — adaptive layout for every screen size
